# 아키텍처 및 기능 리뷰

## 확인할 자료

1. AGENTS.md의 패키지 구조와 의존성 규칙
2. 작업 대상 기능의 docs/features/ 명세
3. 관련 코드와 테스트

## 검토 순서

1. 변경된 코드와 관련 코드를 읽는다.
2. 계층 간 의존성이 AGENTS.md의 규칙을 지키는지 확인한다.
3. 도메인이 유효하지 않은 상태로 생성될 수 있는지 확인한다.
4. 기능 명세의 정상·실패 조건이 구현되어 있는지 확인한다.
5. 테스트가 실제 요구사항을 검증하는지 확인한다.
6. 필요하면 검증 명령을 실행하고 결과를 확인한다.

## 결과 작성

- 중요한 문제부터 정리한다.
- 문제의 파일 위치, 발생 조건, 영향을 설명한다.
- 확인한 사실과 추가 확인이 필요한 추측을 구분한다.
- 실행한 검사와 실행하지 못한 검사를 구분한다.
- 문제가 없으면 검토 범위와 남은 한계를 설명한다.

## 주의사항

- 리뷰 요청만 받은 경우 코드를 수정하지 않는다.
- 테스트 통과만으로 기능 완성을 판단하지 않는다.
- 규칙 위반을 숨기기 위해 테스트나 명세를 완화하지 않는다.
