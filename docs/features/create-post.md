# 게시글 생성

## 목적

제목과 본문을 입력받아 게시글을 생성한다.

## 요구사항

- 제목은 null, 빈 문자열, 공백만 있는 문자열을 허용하지 않는다.
- 본문은 null, 빈 문자열, 공백만 있는 문자열을 허용하지 않는다.
- 제목은 최대 100자, 본문은 최대 5,000자까지 허용한다.
- 유효한 제목과 본문의 앞뒤 공백은 제거하지 않고 그대로 보존한다.
- 길이는 앞뒤 공백을 포함한 Java String.length() 기준으로 계산한다.
- 길이 제한은 domain, 요청 DTO 검증, DB 컬럼 설정에 반영한다.
- 검증에 실패하면 게시글을 저장하지 않는다.
- 저장에 성공하면 생성된 게시글 ID를 반환한다.
- 제목과 본문의 유효성 규칙은 domain에서 보호한다.
- HTTP 요청 검증과 오류 응답 처리는 presentation에서 담당한다.

## API

POST /api/v1/posts

요청 예시:

{
"title": "첫 번째 게시글",
"content": "본문입니다."
}

성공:
- HTTP 201
- 응답 본문: {"id": 1}

입력 오류:
- HTTP 400
- 오류 원인을 설명하는 message 반환
- 응답 형식: {"message":"오류 설명"}
- 여러 필드의 오류는 하나의 message로 합칠 수 있다.
- 테스트는 여러 오류 메시지의 순서에 의존하지 않는다.

## 완료 조건

- 정상 입력으로 게시글이 저장된다.
- 생성된 게시글 ID가 응답에 포함된다.
- 제목과 본문의 null·빈 문자열·공백 입력을 거절한다.
- 제목 100자와 본문 5,000자는 허용하고, 각각의 최대 길이를 초과하면 거절한다.
- 유효한 입력의 앞뒤 공백을 보존한다.
- 잘못된 입력으로 저장소가 호출되지 않는다.
- domain은 Spring·JPA에 의존하지 않는다.
- 테스트와 빌드가 통과한다.
